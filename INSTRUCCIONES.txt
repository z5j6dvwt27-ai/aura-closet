AURA CLOSET 1.1 — ACTUALIZACION SIN PERDER TUS PRENDAS

1. ABRE LA APP EN TU IPAD y entra a AJUSTES.
2. Pulsa EXPORTAR ARMARIO. Guarda el JSON como respaldo en Archivos/iCloud.
3. Abre github.com/z5j6dvwt27-ai/aura-closet en tu navegador.
4. En la pestaña Code usa Add file > Upload files.
5. Selecciona los archivos index.html, app.js, style.css, sw.js, manifest.webmanifest y los dos iconos; sube los archivos, NO el ZIP.
6. GitHub permite agregar archivos nuevos, pero puede rechazar nombres duplicados desde Upload files. Si los rechaza, actualiza los archivos de texto individualmente usando el lapiz (Edit this file) y pega el contenido de cada archivo de este paquete.
7. Commit changes. GitHub Pages publicara la actualizacion tras unos minutos.
8. Cierra y vuelve a abrir AURA CLOSET; si sigue la version vieja, recarga desde el navegador.
9. Revisa que tus prendas sigan presentes. Si faltan, usa AJUSTES > IMPORTAR COPIA.

NOTA: Los datos del armario se guardan en el dispositivo, NO se sincronizan con GitHub. La version 1.1 no cambia el nombre de la base de datos ni elimina registros.
NUEVO: Marca/talla/precio, prendas favoritas, combinador por clima manual, consejos locales, registro de usos, semana visual y resumen de armario.
GRATIS: No usa modelos de IA de pago ni servicios de sincronizacion.
